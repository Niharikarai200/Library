# Library Management System

A beginner-friendly Library Management System built using Python.

## Features
- Add new books
- Search for books
- Issue books
- Return books
- Display all books

## Technologies Used
- Python 3
- Dictionary
- Functions
- While Loop
- If-Else Statements

## How to Run

1. Clone this repository.
2. Open the project folder in your terminal.
3. Run the following command:

```bash
python library.py
```

## Storage
Books are stored in a Python dictionary. Data is temporary and will be lost when the program exits.
